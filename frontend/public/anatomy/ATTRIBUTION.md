# 3D anatomy attribution

Medicaloop loads selected 3D organ files from the
[Human Reference Atlas 3D Reference Object Library](https://humanatlas.io/3d-reference-library)
(HuBMAP / Indiana University).

License: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

The GLB files are fetched at runtime from public CDNs. They are not re-hosted in this repository.

Citation (v1.2 objects):

Schlehlein, Heidi, Bruce W. Herr II, Ellen M. Quardokus, Andreas Bueckle, and Katy Börner. 2022.
HuBMAP CCF 3D Reference Object Library. https://humanatlas.io/3d-reference-library

Source data includes the NIH Visible Human Project (Spitzer et al. 1996; Ackerman 1998)
and, for the brain, the Allen Human Reference Atlas.

The full-body bone/joint chart, digestive tract, ENT head, and endocrine glands use BodyParts3D PART-OF polygon data from the
[Database Center for Life Science](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html)
(LSDB archive). Compact labeled GLBs are generated by `scripts/build_skeleton_glb.py` and `scripts/build_bp3d_parts.py`.

Eyes, skin, brain, and spinal cord load from the Human Reference Atlas (same CC BY 4.0 license).
